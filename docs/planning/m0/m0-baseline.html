M0.5 — القرارات (أجبت عليها 19 تشرين الثاني)

  1. قاعدة hcsyria_micro_id: قرار قاعدة حلب قديمة. تُعامل كحلب مثل باقي المحافظات، وستصل نسخة حلب النهائية لاحقاً وتُعتمد هي. لا يوجد مركز سادس.
  2. فحص الرقم الوطني في DISC وF2F: قرار اتصال قراءة فقط بقواعد DISC وF2F، فحص فوري (M4.4).
  3. الشاشات المخفية: قرار تُنقل: ملحقا الزراعة والتأهيل، المشتريات، الملفات التنفيذية، الخط الزمني للقرض. المحادثة لا تُنقل.
  4. نسخة حلب النهائية: بانتظارها للتأكد أنها مثل باقي المدن (+18 جدولاً). لا تمنع البدء بـ M1.
  5. لاحقاً: توكن Kobo ووصول الخادم لـ API (قبل M4.14)، ومدة التشغيل المتوازي مع البرنامج (قبل M7).
