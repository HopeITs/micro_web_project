# Official papers (M4.20): what is built and how it works

Status on 22 November 2026, branch `official-papers`. Decisions of the owner are in [inventory.md](inventory.md) section 11.

## 1. The blank papers library (done)

- **Catalogue:** `config/papers.php`, generated by `php tools/papers/clean-templates.php "<papers folder>" "<output folder>"`. It lists the 33 papers and 241 entries (paper, city, signing place, version, format, SHA-256).
  - Idlib is part of Aleppo (place `IDL`). Al Wadi is its own city `WAD`. The papers folder says `DMS` for Damascus; the database says `DAM`, and the catalogue uses `DAM`.
  - The Word files are emptied of the typed boxes (sample names, national numbers, amounts, dates, labels): the full-page background picture and the box positions stay. A scan of every cleaned file finds none of the sample data. The PDFs are copied unchanged.
  - The tool is reproducible: a fixed time on the rewritten parts means two runs give identical files and an identical catalogue.
  - The misnamed file in the Latakia folder (a stray kasra, `حلب` inside) is an Aleppo copy and is not listed twice.
- **Files:** not in git (50 MB). `php artisan papers:import "<output folder>"` checks every file against its SHA-256 and installs them in `storage/app/private/papers` only if all match.
- **Page «الأوراق الرسمية»** (sidebar, Tools): papers by stage, a file per city and version, city/version/search filters, download of the blank Word or PDF (audit event `papers.downloaded`). A reader sees the cities where they hold `projects.view`.

## 2. The print engine (done)

- **Components** `resources/views/components/paper/`: `document` (standalone A4 page with the print button), `page` (the letterhead picture and the city footer, repeated if a page runs on), `field` (label and dotted line), `opts` (round ticks), `grid` (bordered table that grows with the data and keeps blank rows like the paper).
- **Letterhead:** `public/assets/brand/checklist-header.png` is exactly the paper's header. The footer address and mobile per city are in `App\Services\Papers\PaperCity` until the per-city settings of schema v1.4 exist (Idlib prints Aleppo's; Al Wadi prints Homs's).
- **`ArabicAmountInWords`** for the legal papers (e.g. 256000000 → «مئتان وستة وخمسون مليوناً»), with the counting rules for round hundreds, thousands and millions.
- **Audit:** `papers.printed` (the paper in `decision`, e.g. `paper:F03`) and `papers.downloaded`.
- **Review page** `/papers/review/{form}`: the original paper beside the redraw for a chosen project, so staff or the lawyer can compare before the wording is approved. The application print and the original are the only pages the site lets itself frame.

## 3. The application form print (done)

- **Route** `applications.print` (`/applications/{project}/print`), button on the project page. Permission is `applications.view` in the project's city (the same as opening it).
- **Full form (F03):** five sheets as on the paper: (1) project and story, (2) personal information and work, (3) education, courses, project premises and energy, agreements, budget, (4) family, losses, illnesses, (5) assets, other aid, debts, help, energy at home, declaration and signatures. Each sheet fills one printable A4 page; tables grow and the letterhead and footer repeat if more rows are entered.
- **Preliminary form (F02):** its own two-sheet layout as on its paper; the stage of the application picks the form.
- Every list value prints as its name in the page language; the beneficiary's family and household counts are read from the person.

## 4. Assumptions to confirm with the owner

1. **«هل لديك مانع؟»** (five questions): the program stores `agreement_1..5` as «موافقة». A stored agreement prints as **«لا»** (no objection).
2. **Required capacity:** the paper asks for ampere or watt; the program stores the number and a type code. The print shows the number only.
3. **Birth:** the paper's «المواليد» is printed as the year, as in the inventory.
4. **Illness, assets and other aid tables:** the paper has name and role columns; the program stores these rows on the beneficiary, so the beneficiary's name and role are printed.
5. **Gaps G8:** the work type and income of family members are blank (the program does not store them).
6. **Photo box:** left empty (the personal photo joins when the paper is printed from the attachments, M4.11).
